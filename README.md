## 她的家不在这个仓库里

她的日记、表情包、图片、声音、模型放在同级的 `lanyuxi-home\` 目录：

```
lanyuxi-home\          ← 永不入库、永不上传
├─ diary\to-owner\     表日记（给主人看）
├─ diary\private\      里日记（只给她自己）
├─ stickers\           表情包，按情绪分 happy / speechless / coy / fierce
├─ images\             图片库
├─ voice\              参考音频与合成缓存
└─ models\             Live2D 模型
```

目录名一律英文（避开 Python / ffmpeg / 批处理的编码坑），每个文件夹里放一个中文名的说明 `.txt`。
