## 会话怎么分（按体量换段）

| 项 | 规则 |
|---|---|
| 会话 id | `lanyuxi-msg2-001`、`-002`……（顺序号，与日历无关） |
| 切分 | **只按体量**：用到上下文窗口的 **50%（可调 10–90）** 才开下一段，与日历无关 |
| 标题 | 这一段的头一句话（最多 12 字）+ 日期，如「在吗_26年11月06号」；同一段跨天写成「话题_26年11月06号-11月08号」 |
| 工作区 | 所有会话挂在 `E:\dsh-foundry\lanyuxi-msg`，DSH 侧标题「蓝余汐」；`lanyuxi-home` 只放素材 |
| 跨桶 | 新段第一条消息会把**上一段会话 id** 交给她，提到旧事时用会话检索去查 |
| 推荐值 | 50%：<40% 基本无损；50% 起丢细节；70% 后忘约束；90% 明显变笨 |
| 备份 | 换段时必备份；之后按设定间隔（默认 24 小时，面板可调 1–72、也可整体关掉）检查，**仅当近 12 小时有聊天、且会话确实有新写入**才备；**备份不自动清理**（目录会一直长，要定期手动清）；面板另有「立即备份」与「打开备份文件夹」 |
| 文本记录 | 每条收发都追加到 `lanyuxi-msg\transcript\<年-月>\<日>.md`，可直接喂 RAG（以后做） |
| 时间感知 | 每天第一条消息带【现在是 2026-11-06 10:53 星期X】，其余带【HH:mm】 |
| 回复 | 每条收到的消息都必须调 `qq_send` 回一句；只在会话里说不调工具，主人收不到 |
| 为什么 | 按「装不下」切，而不是按日历切：既不会三天一到就断，也不会聊爆；跨段记忆靠检索补，不靠无限累积 |

## 人格卡

她的性格写在 `E:\dsh-foundry\lanyuxi-home\persona\人格卡.md`（外加同目录 `纠正清单.md`）。
这两份文件通过 `systemPrompt.section` 进入她的系统提示，**不进用户消息**，所以对话记录里只有你和她说的话。
改文件不用重启，下一条消息就生效。

同目录还有两份：
- `称呼.txt` —— 她怎么叫你，一行多值（`老大，主人` / `老大/主人`），**越靠前越优先**，她按心情挑
- `禁说清单.md` —— 出站拦截词表，命中当场拒发

## 守门员

三条底线写成代码，不靠她自觉：

| 拦截 | 实现 |
|---|---|
| 说漏 | 出站比对 `lanyuxi-home\persona\禁说清单.md`，命中即拒发并告诉她命中了哪个词 |
| 超量 | 群发言每日上限（默认 10 条）与私聊分开计数；私聊 5 秒、群聊 5 分钟冷却 |
| 场合 | 白名单外的群、非主人私聊，入口就过滤，模型看不到 |

## 语音

三级引擎，装不上就自动往下降（`auto` 模式）：

| 引擎 | 出声速度 | 说明 |
|---|---|---|
| GPT-SoVITS | CPU 每句约 150 秒 | 音色最像（宫园薰权重）；**默认不开实时合成**，只有预热过的句子能秒发 |
| edge-tts | 秒级 | 在线，要能连微软服务器；连不上就落到 SAPI |
| Windows SAPI | 约 1 秒 | 离线兜底，机器音 |

- 常用句写在 `lanyuxi-home\voice\phrases.txt`（现在 12 句），面板可一键预热；缓存里现有 8 条 wav，**没全预完**，没预到的句子按现在的 `voiceRealtime: false` 是发不出语音的
- 合成语言可选**中文 / 日语 / 英语**（默认中文，跨语种带一点口音）；参考音频的原文在 `voice\ref.txt`，换切片要连文本一起换，否则开头会有杂音
- 面板里能选引擎、填安装路径、启停引擎、试听任意一句（30 字内）；合成走异步任务，进度条显示真实进度
- 还没做：**两档情绪**（需要第二段参考音频，`qq_send` 的 `emotion` 参数已先删掉，不做假能力）
- 已做：**合成失败自动改发文字**（语音炸了不会把文字一起丢掉）；慢引擎没预热过的句子发语音会失败，这时她会改用文字

## 她现在会记事（记忆 v0）

2026-11-12 起，她身边多了一本账：四条追加日志，全在 `lanyuxi-home\memory\`（纯文本、能手改、能 `git diff`，永不进 git）。**不用数据库**——她一天几十条消息，扫一遍是毫秒级。

| 文件 | 记什么 |
|---|---|
| `events.jsonl` | 发生过什么（收到并投递了的消息、真的下发了「写今天两篇日记」的任务） |
| `memories.jsonl` | 记住了什么（提炼后的记忆） |
| `skills.jsonl` | 会了什么（技能 + 证据） |
| `personality.jsonl` | 她变成什么样了（人格采样与正式变更） |

字段以 [`docs/记忆v0-数据契约.md`](docs/记忆v0-数据契约.md) 为准，改格式先改那份文档。写日志失败只记 `diag.memoryError` + 一行 warn，**绝不影响她回消息**。

面板因此多了一页 **成长档案**（在「语音引擎」之后、「权限与刹车」之前）：上半是成长时间线（时间 · 谁 · 一句话 · 平台），下半是人格档案（人格卡前 300 字 + 五维：主动/好奇/幽默/黏人/嘴硬 + 变更历史）。接口只读：`GET /lanyuxi/growth`。

**空态是功能的一部分**：没有事件就显示「今天还没记事」，人格采样不足 3 条就显示「还没有采样，画了也是假数据」——不拿假数据凑数。

v0.5 起她**能读也会用**：

- 工具 `diary_write` —— 两篇日记一次交上去，**由插件落盘**（她的会话工作区是 `lanyuxi-msg`，家目录在外面，用她自己文件工具写会被沙箱拦下并弹审批）
- 工具 `memory_save` —— 值得记的事自己写进 `memories.jsonl`（类型 / 可见性 / 200 字内）
- 工具 `personality_record` —— 每周一次「这周你觉得自己有什么变化」，五个 0–1 维度 + 一句为什么
- 每轮对话前自动检索：最多 5 条、**总长 ≤300 字**；**群聊只捞 shared/public，私聊才用 private**；检索失败就当没记住，绝不影响回话
- id 跨重启唯一（写前从文件续号），不会因为 DSH 重载把记忆指错经历

什么时候才换数据库：`events.jsonl` 过 5 万行、或要做「按意思想起相关的事」时。换存储不动接口形状，界面一行都不用改。

## 开发

- 插件本体就是仓库根的两个文件：`index.js`（Host）与 `client.js`（界面）。改完要在 DSH 里重载插件才生效
- 白名单群、冷却、每日上限、换段阈值、语音引擎参数都在 `cordis.patch.yml`
- 语音要先有 GPT-SoVITS 的 API（`api_v2.py`，默认 `127.0.0.1:9880`）；插件装载 5 秒后会按所选引擎自动拉起，起不来就看引擎自己的日志
- 面板接口都是 `/lanyuxi/*`，浏览器直接访问能看到 JSON
